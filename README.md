Unfortunately, hand momentum is not tracked by the game. This means that jacket flying and kobold weapon switching doesn't work as intended. I plan to fix this soon.

**CONTROLS:**

Q/E - Y/B (Ability)

X/C - X/A (Dash)

R/G - Left/Right Grip (Grab)

T - Clump hands together (Toggle)

LMB/RMB - Left/Right Trigger (Attack)

W/A/S/D - Left Joystick Up/Left/Down/Right (Move)

Shift/Space - Right Joystick Down/Up (Crouch/Jump)
